# Dashboard-Katalog-Peraturan-Wali-Kota-Sibolga
Dashboard Katalog Peraturan Wali Kota Sibolga adalah aplikasi web untuk mengelola, menyimpan, mencari, memfilter, dan mengakses dokumen Peraturan Wali Kota secara digital guna mendukung tertib administrasi dan kemudahan akses informasi di lingkungan Pemerintah Kota Sibolga.
